# M2M Global Consultants website

Static one-page site for m2mglobalconsultants.com (study abroad & visa consultants, Faisalabad).

- `index.html` – the whole site (HTML, CSS and JS in one file)
- `logo.png`, `icon.png` – brand images
- `CNAME` – custom domain for GitHub Pages

Deploy: push to a GitHub repo, then Settings → Pages → Deploy from branch `main` / root.

Website by Masmatix Innovations.
